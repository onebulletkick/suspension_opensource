# 02 设计目标

## 这章解决什么问题

悬架设计不是从画硬点开始，而是从车辆目标和约束开始。本章说明如何把车手反馈、上一代问题、规则边界、整车参数和跨组接口转成可检查的悬架设计目标。

目标不是写一组好看的口号，而是建立一份能被计算、仿真、装配、测试和答辩复核的设计输入。

## 设计输入

| 输入项 | 需要确认什么 | 悬架设计会受什么影响 | 记录方式 |
| --- | --- | --- | --- |
| 车辆目标 | 今年更重视稳定性、轻量、可调、可靠、低速灵活性还是极限性能 | 几何指标、侧倾刚度分配、可调范围、结构裕度 | 目标表，写明优先级和验证方式 |
| 轮胎/轮辋 | 轮胎尺寸、推荐轮辋、轮胎数据覆盖范围、轮辋内包络 | 轮心位置、主销参数、制动空间、硬点边界、轮胎模型 | 轮胎包络图、轮辋约束、模型版本 |
| 车架节点/空间 | 可用节点、管件走向、座舱和维护空间、安装面 | A 臂内点、减振器/摇臂布置、载荷路径 | 坐标系一致的接口表 |
| 制动/传动边界 | 卡钳、制动盘、轮毂、电机/链传动/半轴等包络 | Upright 设计、转向节空间、杆件避让、极限姿态干涉 | 包络文件、接口评审记录 |
| 气动/车身边界 | 离地高度敏感性、地板/扩散器/翼面空间、车身拆装 | 偏频、行程、侧倾控制、推杆/拉杆空间 | 气动高度需求和装配边界 |
| 车手反馈 | 过弯响应、制动稳定性、出弯牵引、颠簸路感、可预测性 | 参数优先级、测试计划、调校方向 | 反馈表，区分现象和推测原因 |

## 判断逻辑

RCD / RCVD 视角下，目标不是一句性能口号，而是能一路传递到轮胎、几何、簧上参数、载荷、仿真和验证证据的约束链。

### 目标要能验证

每个目标后面都应写清楚验证方法。比如“提高稳定性”太模糊，可以拆成制动时前束变化检查、稳态转向梯度、出车日志中的方向盘修正量、车手对临界状态的描述等。

### 先区分约束和偏好

规则、轮辋内空间、车架安装点、制动卡钳和安全要求通常是强约束；外倾变化率、侧倾中心高度、抗俯仰比例、可调范围则常常需要在多个目标之间取舍。不要把偏好写成不可动的规则，也不要把真正的硬约束留到 CAD 后期才发现。

规则检查要写具体版本和检查日期。比如 wheel travel、jounce、安装点可视性、wheelbase / track、轮辋间隙和关键紧固件要求，应该在目标阶段变成检查项；规则最低值不等于性能目标。更完整的规则门槛示例见 [高级 01 设计目标](advanced/01-design-targets.md)。

### 早期目标可以估算，但要写条件

项目早期的质量、质心、气动载荷、轮胎刚度、目标侧向加速度可能还没有实测值。可以用估算值启动设计，但必须记录来源、修订日期、适用范围和触发更新的条件。例如：当整车质量估算变化超过某一阈值，偏频、轮端刚度和载荷工况应重新检查。

### 取舍要能解释

悬架参数之间常有冲突：更强的车身姿态控制可能带来更高轮胎动载；更激进的主销参数可能改善反馈但增加转向力矩；更大的可调范围可能增加质量和制造复杂度。设计记录应保留为什么接受这个取舍，而不是只留下最终数值。

## 输出

- RCD / RCVD 知识映射：每个悬架目标对应的车辆动态概念、设计文件和验证证据。

| 输出物 | 最低内容 |
| --- | --- |
| 悬架设计目标表 | 目标、单位、当前值/范围、来源、验证方法、负责人 |
| 跨组接口清单 | 受影响组别、接口参数、交付格式、确认日期 |
| 第一版整车参数表 | 质量、轴距、轮距、质心、轮胎、气动假设、制动/传动边界 |
| 风险和不确定性清单 | 哪些输入还是估计值，何时更新，更新后会影响哪些章节 |
| 设计评审节奏 | 目标冻结、硬点评审、布置评审、仿真评审、校核评审、出车前评审 |

## 常见错误

- 直接复制旧车参数，却没有检查新规则、新轮胎、新车架和新气动目标。
- 把“感觉更好”写成设计目标，却没有定义测试和数据证据。
- 只和车架确认硬点，不和制动、传动、气动、车手和制造确认空间。
- 早期估算值后来变了，但没有回头更新弹簧、阻尼、载荷和仿真模型。
- 只写最终目标，不写被放弃方案和取舍理由。

## 验证方式

- 规则检查：确认尺寸、可调结构、紧固件、材料和安全相关条款没有冲突。
- 包络检查：用 CAD 或简化模型检查轮胎、轮辋、制动、转向、车架和车身空间。
- 一阶计算：用质量、质心、轴距、轮距和轮胎假设做载荷转移、频率、侧倾和制动稳定性初算。
- 接口评审：让受影响组别确认坐标系、单位、版本和交付日期。
- 设计复盘：每次输入更新后，检查是否触发硬点、弹簧阻尼、载荷或仿真重算。

## 和其它组的接口

| 组别 | 需要交互的信息 | 悬架应交付什么 |
| --- | --- | --- |
| 车架 | 安装节点、管件空间、载荷路径、可焊/可加工区域 | 硬点需求、支座载荷、维护空间说明 |
| 转向 | 转向机位置、拉杆空间、转向角、转向力矩目标 | 主销参数、转向拉杆点、bump steer 目标 |
| 制动 | 盘/卡钳/油管空间、制动力需求、散热边界 | Upright 空间需求、极限姿态干涉结果 |
| 传动 | 半轴、链传动或电机空间，跳动行程边界 | 轮心和杆件包络，极限行程说明 |
| 气动/车身 | 离地高度窗口、侧倾/俯仰敏感性、车身拆装 | 目标车高、行程、姿态变化和可调范围 |
| 车手/测试 | 操控现象、测试路线、可接受调校工作量 | 目标解释、调校表、测试后问题清单 |
